= ol.busker.runtime


Multi-generation runtime lifecycle for Busker.

[#start-BANG-]
== start!




[source,clojure]
----
(start! user-config)
----

Start a new Busker server from `user-config`.

[#reload-BANG-]
== reload!




[source,clojure]
----
(reload! server-handle user-config)
(reload! {:keys [busker/lifecycle-gate busker/state] :as server-handle} user-config opts)
----

Compile and activate a new runtime snapshot for `server-handle`.

link:https://github.com/outskirtslabs/busker/blob/main/src/main/clojure/ol/busker/runtime.clj#L316-L364[source,window=_blank]

[#stop-BANG-]
== stop!




[source,clojure]
----
(stop! {:keys [busker/lifecycle-gate busker/state] :as server-handle})
----

Synchronously stop `server-handle`, waiting for active and draining
generations to quiesce.
