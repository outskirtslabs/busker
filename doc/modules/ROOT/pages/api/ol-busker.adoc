= ol.busker


Public lifecycle API for Busker.
See xref:api/ol-busker-config.adoc[`ol.busker.config`] for the `config` map accepted by <<start-BANG-,`start!`>> and
<<reload-BANG-,`reload!`>>.

[#start-BANG-]
== start!




[source,clojure]
----
(start! config)
----

Start a Busker server from `config` and return an opaque server handle.

See xref:api/ol-busker-config.adoc[`ol.busker.config`] for the config shape.

[.api-source]
link:https://github.com/outskirtslabs/busker/blob/main/src/main/clojure/ol/busker.clj#L8-L13[source,window=_blank]

'''

[#reload-BANG-]
== reload!




[source,clojure]
----
(reload! server config)
(reload! server config opts)
----

Compile and activate a new runtime snapshot for `server` from `config`.

See xref:api/ol-busker-config.adoc[`ol.busker.config`] for the config shape.

[.api-source]
link:https://github.com/outskirtslabs/busker/blob/main/src/main/clojure/ol/busker.clj#L15-L22[source,window=_blank]

'''

[#stop-BANG-]
== stop!




[source,clojure]
----
(stop! server)
----

Synchronously stop `server`.

[.api-source]
link:https://github.com/outskirtslabs/busker/blob/main/src/main/clojure/ol/busker.clj#L24-L27[source,window=_blank]

'''

[#state]
== state




[source,clojure]
----
(state server)
----

Return pure runtime state for `server`.

The returned state includes the normalized config snapshot.
See xref:api/ol-busker-config.adoc[`ol.busker.config`] for that config shape.

[.api-source]
link:https://github.com/outskirtslabs/busker/blob/main/src/main/clojure/ol/busker.clj#L29-L35[source,window=_blank]
