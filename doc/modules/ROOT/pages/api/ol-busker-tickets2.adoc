[#acquire-ticket-state-BANG-]
== acquire-ticket-state!




[source,clojure]
----
(acquire-ticket-state! current-ticket-state compiled-config config-snapshot)
----

Return the next process-local ticket state for `compiled-config`.

`current-ticket-state` is the currently reusable ticket state from runtime.
`config-snapshot` should be the normalized pure-data config snapshot so
storage-backed reuse decisions can compare sharing boundaries without
depending on resolved runtime objects.
