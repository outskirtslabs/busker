[#start-worker-BANG-]
== start-worker!




[source,clojure]
----
(start-worker! loop-fn message-handler wakeup-receiver & {:keys [thread-name-prefix] :or {thread-name-prefix "h2o-evloop"}})
----

Start a worker on a platform thread (daemon).

 Parameters:
 - loop-fn: function called for each loop iteration: (worker, state) -> state
 - message-handler
 - wakeup-receiver

 Options:
 - :thread-name-prefix - prefix for thread name (default 'h2o-evloop')

 Returns: worker

[.api-source]
link:https://github.com/outskirtslabs/busker/blob/main/src/main/clojure/ol/busker/evloop.clj#L108-L136[source,window=_blank]
